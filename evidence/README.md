# Mosoo Execution Evidence & Verification Traces

This directory contains deterministic execution manifests, gas reports, and state transition verification logs for the Mosoo Ethereum Consensus & State Attestation module.

## Evidence Sources & Directory Structure

- **`testnet-v03/`** *(Live On-Chain LEZ v0.3.1 Deployment & Execution Manifest - Sextant Standard)*:
  Contains the fully mined, live on-chain deployment and 12-step lifecycle execution manifest captured directly on the public **Logos Execution Zone (LEZ) Testnet v0.3.1** (`https://testnet.lez.logos.co`):
  - `mainnet/run.tsv`: Standard run manifest of all 7 ELF code segments (blocks 77987-78000), CreateHeader tx (block 78002), and all 12 lifecycle steps (blocks 78005-78025) with exact tx hashes, compute/storage gas breakdown, and verdicts.
  - `mainnet/verify.txt`: Cryptographic on-chain verification log generated by `scripts/verify-lez-deployment.py` (22/22 checks passed).
  - `mainnet/mutation-test.txt`: Verifier mutation test report proving 7/7 deliberate tamper mutations fail-closed.
  - `mainnet/README.md`: Reproduction guide with direct RPC `curl` instructions to independently verify every mined block and account state on-chain.

- **`public-testnet-v03/`** *(Live On-Chain Public Testnet Evidence)*:
  Contains live on-chain execution traces captured against the active public **Logos Execution Zone (LEZ) Testnet** (`https://testnet.lez.logos.co`, block height > 68,399) and **Ethereum Sepolia** (`MosooLocker.sol` at `0x74625D...`, block 11989329):
  - `sequencer_verification.txt`: Live LEZ testnet consensus, block progression, fee state, and gas cap verification.
  - `live_bridge_execution.txt`: Live two-way bridge lifecycle trace verifying Sepolia on-chain deposit (`0x743aea...5882`), 3-Tx split light client update, 1:1 `mETH` minting, and burn-to-unlock settlement.

- **`sequencer-harness-v04/`**:
  Contains deterministic execution manifests generated by Mosoo's standalone LEZ v0.4 Sequencer Test Harness (`tests/sequencer_e2e_tests.rs`). It executes the full 7-step consensus and consumer lifecycle across simulated blocks 500,000 to 500,006, followed by 5 adversarial rejections.
  - `run.tsv`: Tab-separated manifest of all 12 lifecycle transactions, block numbers, transaction hashes, compute gas, storage gas, and verdicts.
  - `verify.txt`: Cryptographic verification log generated by `scripts/verify-evidence.py`.

- **`verify_all_output.txt`**:
  Full test suite verification trace capturing 336 passing tests (320 Rust unit, integration, adversarial, regression, and doc tests across all workspace crates + 16 Foundry EVM tests for MosooLocker), zero compiler or Clippy warnings (-D warnings), and execution manifest verification.

- **`pre_release_acceptance_matrix.txt`**:
  Full pre-release test matrix, compiler checks, and clippy verification report across all 5 workspace crates (`mosoo-core`, `methods/guest`, `daemon`, `cli`, and consumers).

- **`adversarial_regression_trace.txt`**:
  Adversarial mutation traces validating 42 attack scenario rejections and 58 invariant regression tests with zero compiler warnings.

- **`public-testnet-v04/`** *(Target Public Devnet)*:
  Reserved for live public testnet transaction hashes, RPC endpoints, and on-chain account state proofs upon public network freeze by Logos Core team.

## Reproducing Verification Locally

You can verify the entire manifest, gas limits, and cryptographic transaction hashes with:

```bash
# Python verification script (verifies 7 applied transactions and 5 adversarial rejections)
python3 scripts/verify-evidence.py --manifest evidence/sequencer-harness-v04/run.tsv
# On Windows: py -3 scripts/verify-evidence.py --manifest evidence/sequencer-harness-v04/run.tsv

# Manifest mutation verification (validates verifier fail-closed behavior across 7 mutation attack scenarios)
python3 scripts/test-evidence-mutation.py

# Live sequencer test harness (recomputes all hashes from scratch)
cargo test --test sequencer_e2e_tests -- --nocapture
```
