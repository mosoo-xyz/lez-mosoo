# Execution Evidence & Verification Traces

This directory holds live deployment traces for Mosoo's LEZ v0.3.1 program (`mosoo_lc`), offline sequencer harness manifests targeting LEZ v0.4, and local test runner logs.

---

## Directory Contents

- **[`mosoo-testnet-v03/`](mosoo-testnet-v03/README.md)** — Live LEZ v0.3.1 deployment (`Co5EYuBRRS21wiawBQRXjMyEBUbbzquZM6LmNHYYo7Fg`, ImageID `961a7e12...`), 6 ELF segments (blocks `81142`–`81148`), 9 Mainnet-backed transactions (`81154`–`81163`), `r0vm 3.0.5` local cycle measurements (`local_simulation.txt`), and `30/30` live RPC + PDA decoding output (`verify.txt` from `scripts/verify-mosoo-lez.py`).
- **[`sequencer-harness-v04/`](sequencer-harness-v04/)** — Deterministic offline sequencer manifest (`run.tsv`, `verify.txt`, `mutation-test.txt`) generated by `mosoo-core/tests/sequencer_e2e_tests.rs` across simulated blocks `500,000`–`500,006` (7 applied steps + 5 adversarial refusals). Upstream public LEZ `v0.4` is not released yet.
- **`verify_all_output.txt`** — Saved run of `scripts/verify_all.ps1` covering `cargo check`, `331` Rust workspace tests, `20` Foundry EVM tests (`contracts/test/MosooLocker.t.sol`), `clippy`, `fmt`, `verify-evidence.py`, `test-evidence-mutation.py`, and `verify-mosoo-lez.py`.
- **`pre_release_acceptance_matrix.txt`** — Saved acceptance output including `cargo fmt`, `cargo clippy`, `cargo audit`, workspace tests, Foundry tests, `verify-mosoo-lez.py`, and `testnet-two-way-bridge.py --mode live`.
- **`adversarial_regression_trace.txt`** — Trace of `50` adversarial mutation tests (42 vectors) and `58` security hardening regression tests.
- **`public-testnet-v04/`** — Placeholder reserved for public LEZ `v0.4` deployment records once upstream `v0.4` launches.

## Quick Reproduction

```bash
python3 scripts/verify-mosoo-lez.py
python3 scripts/verify-evidence.py --manifest evidence/sequencer-harness-v04/run.tsv
python3 scripts/test-evidence-mutation.py
python3 scripts/testnet-two-way-bridge.py --mode live
cargo test --test sequencer_e2e_tests -- --nocapture
```
