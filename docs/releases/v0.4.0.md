# Mosoo v0.4.0 — LEZ v0.4 Conformance & Production zkVM Attestation Release

## Overview

Mosoo v0.4.0 delivers the production-ready Ethereum Consensus State Attestation Module for the Logos Execution Zone (LEZ), adhering to the **LEZ v0.4 specification** and passing all **18/18 Conformance & Acceptance Tests**.

This release provides trustless verification of Ethereum beacon state, account balances, and receipt logs inside the RISC Zero zkVM, enabling verifiable cross-chain communication and consumer applications on LEZ.

---

## Key Highlights & Capabilities

1. **Core Cryptographic Engine & Consensus Invariants**:
   - **BLS12-381 Aggregate Verification**: Efficient in-guest pairing check over `SyncAggregate` via `blst`.
   - **Fork-Aware SSZ Generalized Index Proofs**: Full support across all Ethereum hard forks: Altair, Bellatrix, Capella, Deneb (32-leaf execution payload trees), Electra, Fulu, and Gloas / Hoodi.
   - **Authenticated Checkpoint Bootstrap**: Cryptographic proof of 512-validator sync committees against beacon state roots with strict chain-id domain separation.
   - **One-Time Admin Authority Bootstrap**: Hardened governance initialization preventing replay attacks (`AlreadyInitialized`).

2. **3-Transaction BLS Split Pipeline (< 10M Gas Cap)**:
   - Splits heavy pairing operations across three atomic transactions (`BeginUpdate`, `MillerUpdate`, `FinishUpdate`).
   - Conforms strictly to LEZ's single-transaction 10,000,000 gas cap with **46%–62% headroom**.

3. **Dual Reference Consumer Modules**:
   - `erc20-receiver`: Trustless ERC-20 transfer receipt verification and synthetic token minting with atomic PDA nullifiers preventing double-claims.
   - `ether-receiver`: Native ETH balance verification and `mETH` wrapped ledger accounting.

4. **Two-Way Cross-Chain Settlement (`MosooLocker.sol`)**:
   - Live canonical locker contract deployed on Ethereum Sepolia (`0x74625D146B8d9413F3c3976B323d94A739be7856`).
   - Security features: 24-hour continuous rolling withdrawal rate limits, 2-day timelocked governance, and independent Guardian emergency pause and veto mechanisms.
